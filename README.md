# Overview

This project constists of a user-friendly personal wardrobe mobile application. The user is able to create a personal account and then his own avatar, by scanning himself. After that, any wardrobe item can be scanned and placed in the app, with the additional option to generate outfits using the above avatar. Additional features include:

* A library of outfits
* Clothes recommendation based on the current wardrobe
* Social features (sharing outfits with friends)

The project is powered by an Expo frontend, built using React Native, Typescript and Tailwind CSS, and a Python backend. These communicate using the FastAPI framework. For the database of the application, MongoDB is the database of choice. Developer instructions can be found in the READMEs of the folders of this repository.
